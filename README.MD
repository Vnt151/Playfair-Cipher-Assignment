# Playfair Cipher Assignment

## Mô tả dự án
Dự án thực hiện cài đặt thuật toán mã hóa Playfair bằng ngôn ngữ Python.

## Ví dụ chạy thử
- **Thông điệp gốc**: DO YOU LIKE TO STUDY A CRYPTOGRAPHY COURSE
- **Khóa (Key)**: PLAYFAIR
- **Kết quả**: [Chạy code để điền kết quả vào đây]

## Cách cài đặt và chạy
1. Đảm bảo bạn đã cài đặt Python 3.
2. Chạy lệnh: `python playfair.py`
